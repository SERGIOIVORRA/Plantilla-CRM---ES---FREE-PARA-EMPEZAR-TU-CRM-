# Contribuciones

Gracias por interesarte en la plantilla.

## Cómo contribuir

1. Haz un fork del repositorio
2. Crea una rama (`git checkout -b mejora/mi-cambio`)
3. Commit de tus cambios
4. Abre un Pull Request describiendo qué has añadido

## Ideas bienvenidas

- Mejoras de UI/UX
- Traducciones / textos
- Integraciones reales (Shopify, webhooks, proxy)
- Correcciones de bugs
- Documentación

## Estilo

- Textos de interfaz en **español**
- Mantener el tema rojo (`#AD221F`) + negro salvo que el cambio lo justifique
